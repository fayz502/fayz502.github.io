# Fayez Portfolio (Starter)

This is a ready-to-upload portfolio starter.

## Edit content
- **Name & tagline:** in `index.html` (Hero section).
- **Projects:** update the cards in Web/Data sections and replace `#` with your GitHub/Notebook links.
- **Gallery:** replace images in `images/`.
- **Contact:** update email, GitHub and LinkedIn links.

## Reorder sections
Move the corresponding `<section id="..."> ... </section>` blocks up/down in `index.html`.
Update the order of links inside the `<ul class="nav-links">` list to match.

## Deploy on GitHub Pages
1. Create a new repository on GitHub (e.g., `fayez-portfolio`).
2. Upload the files (or push with Git).
3. Go to **Settings → Pages**. Under **Build and deployment**, choose **Branch: main** and **/ (root)**.
4. Save. Your site will be available at `https://<username>.github.io/<repo>/` (or `https://<username>.github.io` if you name the repo `<username>.github.io`).
